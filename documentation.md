# 10CT2 Web Apps Project - Web Influence
### Requirements Definition
#### Functional
- Display Functionality
    - Website can be used to view charities, non-profits, donation collections, volunteering work, etc. in the Central Coast and Greater Sydney Region.

#### Non-Functional
- Localised Work
    - Users must be able to input their location (city, suburb, postcode), with the input being used to find nearby charities and volunteering spots.
- Niche Charities
    - Promoting access to smaller charities and non-profits that may be in need of donations or volunteer help.
- Security (?)
    - Program has safeguards in case of malicious user inputs (e.g. invalid/malicious inputs).
