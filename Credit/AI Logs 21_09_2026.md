The basic idea is:

```
ACNC dataset file
```

# **4\. Reading the CSV file**

This is where the JavaScript comes in.

If your file is called:

```
charities.csv
```

you can do:

```
fetch("charities.csv")
    .then(response => response.text())
    .then(data => {
        console.log(data);
    });
```

This tells the browser:

> "Go get `charities.csv`, turn it into text, and give me the contents."

If you open the browser's developer console, you should see the CSV data.

However, CSV files can be a little annoying to process because values can contain commas, quotation marks, etc.

For a school project, I'd recommend using a small CSV library called **Papa Parse** rather than writing your own CSV parser.

You can include it in your HTML:

```
<script src="https://cdn.jsdelivr.net/npm/papaparse@5.4.1/papaparse.min.js"></script>
<script src="script.js"></script>
```

Then your JavaScript becomes much easier.

# **5\. Turning the CSV into a table**

Your `script.js` could start like this:

```
let charities = [];

Papa.parse("charities.csv", {
    download: true,
    header: true,

    complete: function(results) {
        charities = results.data;

        displayTable(charities);
    }
});
```

`header: true` is particularly useful.

Imagine your CSV looks like:

```
ABN,Charity Name,State,Suburb
12345678901,Example Charity,NSW,Sydney
98765432109,Another Charity,VIC,Melbourne
```

Papa Parse turns each row into something like:

```
{
    ABN: "12345678901",
    "Charity Name": "Example Charity",
    State: "NSW",
    Suburb: "Sydney"
}
```

So JavaScript can access:

```
charity["Charity Name"]
```

or:

```
charity["State"]
```

# **6\. Displaying the data**

Here's a simple version:

```
function displayTable(data) {

    let tableHead = document.getElementById("tableHead");
    let tableBody = document.getElementById("tableBody");

    tableHead.innerHTML = "";
    tableBody.innerHTML = "";

    // Create headings
    let headings = Object.keys(data[0]);

    let headerRow = document.createElement("tr");

    headings.forEach(function(heading) {

        let th = document.createElement("th");

        th.textContent = heading;

        headerRow.appendChild(th);
    });

    tableHead.appendChild(headerRow);


    // Create rows
    data.forEach(function(charity) {

        let row = document.createElement("tr");

        headings.forEach(function(heading) {

            let cell = document.createElement("td");

            cell.textContent = charity[heading];

            row.appendChild(cell);
        });

        tableBody.appendChild(row);
    });
}
```

Now the website will automatically look at the columns in your CSV and create the table.

This is useful because you don't have to manually write:

```
<th>ABN</th>
<th>Charity Name</th>
<th>State</th>
```

etc.

# **7\. The important part: multiple pages**

This is actually easier than it sounds.

Let's say your dataset contains **60,000 charities**.

You obviously don't want to put all 60,000 rows on the screen simultaneously.

Instead, you can display:

```
Rows 1–25

[Previous] [1] [2] [3] [4] ... [2400] [Next]
```

The basic concept is:

```
let currentPage = 1;
let rowsPerPage = 25;
```

Then calculate which rows should be displayed:

```
let start = (currentPage - 1) * rowsPerPage;
let end = start + rowsPerPage;

let pageData = data.slice(start, end);
```

For example:

### **Page 1**

```
start = 0
end = 25
```

So:

```
data.slice(0, 25)
```

### **Page 2**

```
start = 25
end = 50
```

So:

```
data.slice(25, 50)
```

### **Page 3**

```
start = 50
end = 75
```

And so on.

# **8\. A simple pagination system**

You could add this to your JavaScript:

```
let currentPage = 1;
let rowsPerPage = 25;

function showPage(data) {

    let start = (currentPage - 1) * rowsPerPage;
    let end = start + rowsPerPage;

    let pageData = data.slice(start, end);

    displayTable(pageData);

    createPagination(data);
}
```

Then:

```
function createPagination(data) {

    let pagination = document.getElementById("pagination");

    pagination.innerHTML = "";

    let totalPages = Math.ceil(data.length / rowsPerPage);

    for (let i = 1; i <= totalPages; i++) {

        let button = document.createElement("button");

        button.textContent = i;

        button.onclick = function() {

            currentPage = i;

            showPage(data);
        };

        pagination.appendChild(button);
    }
}
```

Although, if you have thousands of pages, creating thousands of buttons isn't ideal.

A simpler system would be:

```
[Previous]    Page 23 of 2400    [Next]
```

That's probably what I'd recommend for your project.

# **9\. Searching the dataset**

This is also relatively simple.

Suppose the user types:

```
cancer
```

You can search through the charity information:

```
document.getElementById("search").addEventListener("input", function() {

    let searchText = this.value.toLowerCase();

    let filteredData = charities.filter(function(charity) {

        return Object.values(charity).some(function(value) {

            return String(value).toLowerCase().includes(searchText);

        });

    });

    currentPage = 1;

    showPage(filteredData);
});
```

This searches **all the columns**.

So if the user types:

```
Sydney
```

it could find charities where Sydney appears in the suburb, address, organisation name, etc.

Yes — if you mean **how to build the dataset table using `<table>`, `<tr>`, `<th>`, and `<td>`**, that's actually a great approach for a school project.

## **What each tag means**

Think of a table like a spreadsheet:

```
<table>
    <tr>
        <th>Name</th>
        <th>State</th>
        <th>ABN</th>
    </tr>

    <tr>
        <td>Example Charity</td>
        <td>NSW</td>
        <td>12345678901</td>
    </tr>
</table>
```

*   
  `<table>` \= the entire table

* `<tr>` \= **table row**

* `<th>` \= **table heading**

* `<td>` \= **table data/cell**

So visually:

| Name | State | ABN |
| ----- | ----- | ----- |
| Example Charity | NSW | 12345678901 |

The first `<tr>` contains your headings, and the second `<tr>` contains your first charity.

### **But there's one important thing**

You **don't want to manually write a `<tr>` for every charity**.

If your ACNC dataset has thousands of rows, HTML would become enormous.

Instead, you can have JavaScript create the `<tr>` and `<td>` elements automatically.

For example:

```
function displayData(data) {

    let table = document.getElementById("charityTable");

    table.innerHTML = "";

    for (let i = 0; i < data.length; i++) {

        let row = document.createElement("tr");

        let name = document.createElement("td");
        name.textContent = data[i]["Charity Name"];

        let state = document.createElement("td");
        state.textContent = data[i]["State"];

        let abn = document.createElement("td");
        abn.textContent = data[i]["ABN"];

        row.appendChild(name);
        row.appendChild(state);
        row.appendChild(abn);

        table.appendChild(row);
    }
}
```

Then your HTML could be:

```
<table>

    <tr>
        <th>Charity Name</th>
        <th>State</th>
        <th>ABN</th>
    </tr>

    <tbody id="charityTable">
    </tbody>

</table>
```

JavaScript would effectively turn that into:

```
<tr>
    <td>Example Charity</td>
    <td>NSW</td>
    <td>12345678901</td>
</tr>

<tr>
    <td>Another Charity</td>
    <td>VIC</td>
    <td>98765432109</td>
</tr>
```

automatically.
