# 10CT2 Web Apps Project - Web Influence
### Requirements Definition
#### Functional
- Display Functionality
    - Website can be used to view charities, non-profits, donation collections, volunteering work, etc. in the Central Coast and Greater Sydney Region.
- Contact Features
    - Users can use website to locate and **contact** support groups, charities and more, allowing for proper communication to setup volunteering events and donations.
- Feedback
    - Users can report bugs, or give feedback on features in order to improve the website's UX, functionality, efficiency and utility uses.
- Opt-in and out
    - Organisations can choose to apply to opt-in or out of the program if they desire.

#### Non-Functional
- Localised Work
    - Users must be able to input their location (city, suburb, postcode), with the input being used to find nearby charities and volunteering spots.
- Niche Charities
    - Promoting access to smaller charities and non-profits that may be in need of donations or volunteer help.
- Security (?)
    - Program has safeguards in case of malicious user inputs (e.g. invalid/malicious injections).
- Forums
    - Users can communicate with each other to improve program use, and discuss charities, community events, etc.
